# 引脚接线

外接的东西全部接在底板的 **CEP 排针**（2×20，间距 2.54 mm，所有 IO 都是 3.3 V，**不耐 5 V**）。脚 1 = 3.3 V，脚 2 = GND，脚 3~38 = 信号 `CEP_L1_P`、`CEP_L1_N` … `CEP_L18_N`（奇数脚 P，偶数脚 N，脚号 = 2×L + 1 或 2×L + 2），脚 39、40 空。脚号以板子丝印为准；FPGA 管脚号来自厂商引脚表 `06_CEP管脚定义表-J1.xlsx`。

## 1. 外设接线表

| 外设 | 信号（`mctop.v` 端口） | CEP 脚 | FPGA 管脚 | 接到外设的哪里 |
| --- | --- | --- | --- | --- |
| **步进电机（尾巴）UART，只发不收** | `O_step_tx` | 15 | E17 | 步进驱动器接线排上的 **R/A/H** 脚（串口 TTL 时 = 驱动器的 RX）。驱动器的 T/B/L 脚不接 |
| **霍尔传感器** | `I_hall` | 17 | B17 | 传感器模块的输出脚（**磁铁靠近 = 高电平，离开 = 低电平**） |

电源和地：
- 霍尔传感器模块：**用 CEP 脚 1 的 3.3 V 供电**（用 5 V 供电的话输出也是 5 V，会损坏 FPGA）。步进驱动器和开发板（以及以后的轮子单片机）的 GND 要连在一起。
- 步进驱动器（ZDT X42S 第二代，必须是**串口 TTL 版本**——手册 2.2.1；RS485 版本的 R/A/H 脚是差分电平，FPGA 直接接收不了）：自己的电源另接（10~29 V），**驱动器的 Gnd 脚接 CEP 脚 2（GND）**，不共地串口收不到。驱动器菜单保持出厂设置：`FWType = FW_Emm`、`P_Serial = UART_FUN`、`UartBaud = 115200`、`ID_Addr = 1`、`Checksum = 0x6B`、`MStep = 16`。第一次用要在驱动器菜单里设一次回零零点：先拔掉 R/A/H 那根线（不然 FPGA 上电 1 秒后会让它回旧零点）→ 驱动器断电 → 用手把尾巴拧到正中 → 驱动器上电 → 菜单 `0_Set` → `Set 0` → 插回 R/A/H 线（零点掉电不丢；上电时 FPGA 让驱动器"单圈就近回零"到这个点，见 `hmi_tail.md` §3）。
- 霍尔输入脚在 FPGA 里设了下拉：没接传感器时读到 0（不会误触发喂食）。你的模块如果是反过来的（磁铁靠近输出低），在 `mctop.v` 里把 `mc_hall` 例化处的 `.I_hall (I_hall)` 改成 `.I_hall (~I_hall)`，不用动接线（但下拉就变成"没接传感器 = 误触发喂食"，这种模块请外加上拉 / 自带推挽输出）。

## 3. 要改引脚怎么改

引脚都写在 `src/pin/mc_pin.adc` 里，一行一个端口，例如霍尔传感器：

```
set_pin_assignment { I_hall } { LOCATION = B17; IOSTANDARD = LVCMOS33; PULLTYPE = PULLDOWN; }
```

- **直接改文本（最稳）**：TD 里展开 `constraint_1`，双击 `mc_pin.adc`，把 `LOCATION = ` 后面的管脚号换成上面"空着的 CEP 脚"表里的另一个（所有 CEP 脚都是 3.3 V，可以随便换），保存，再点 **Generate Bitstream**（TD 会自己判断重跑哪些步骤）。
- **用向导**：先 **Syn Opt → Read Design / Optimize Gate** 做完综合，再 **Tools → IO Constraint**，在表里改 Location 列，保存（步骤和截图见 `video_pipeline.md` §7）。
- 只改 `LOCATION` 就行，Verilog 里的端口名、`mctop.v` 都不用动。两个信号不能用同一个管脚；也不要用上面"板载"那张表里的管脚。
- 输入脚不能写 `DRIVESTRENGTH`（TD 会报错）；步进 UART 的发送脚默认上拉（空闲为高）。
