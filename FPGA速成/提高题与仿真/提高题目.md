# Verilog 提高模拟题（两题）

这两题是自行编写的模拟题，不是历年真题。难度参考已有电子钟、计费、密码锁和交通灯题中的较难部分：需要同时处理状态、计数和优先级。题面已约定边界情况，按此实现即可。

文件夹内的 `tb_vending.v`、`tb_elevator.v` 是逐条写激励的 testbench：没有 `step`，主要靠观察波形。`答案` 文件夹是参考答案，建议完成后再看。题面中的“下一上升沿”均以输入在上升沿前稳定为前提；给定 tb 在下降沿改变输入。

## 题一：自动售货与退款控制

饮料价格为 8，余额范围 0～20，金额都是无符号**二进制整数**。`coin_valid`、`buy`、`cancel` 是同步请求，可在同一个上升沿同时为 1。`coin_value` 可输入 0～15。每个上升沿按以下顺序执行：

1. `rst_n=0` 时异步复位：所有输出和内部状态清零。
2. 出货期间（`dispensing=1`），忽略投币、购买、退款请求；余额保持。出货从购买成功的上升沿之后开始，连续高 4 个完整时钟周期，4 个周期后自动结束。出货最后一个上升沿仍忽略输入，下一个上升沿起可接收新请求。
3. 不在出货期间，`cancel=1` 优先级最高：把**该上升沿之前的余额**送到 `refund`，同时 `credit` 清零；该沿的投币和购买均忽略。`refund` 保持一拍，下一上升沿自动清 0；余额为 0 时退款值就是 0。
4. 既没有出货也没有退款时，先处理投币：`coin_valid=1` 则把 `coin_value` 加到余额，超过 20 按 20 计算；否则金额不变。同一上升沿 `buy=1` 时，使用上述加币并限幅后的金额判断购买。
5. 购买金额大于等于 8，扣除 8 并开始出货；不足 8，则保留上述金额并让 `insufficient` 高一拍，不开始出货。其他周期 `insufficient=0`。不用处理机械按键抖动。

```verilog
module vending_ctrl(
    input clk, input rst_n,
    input coin_valid, input [3:0] coin_value,
    input buy, input cancel,
    output reg [4:0] credit,
    output reg dispensing,
    output reg insufficient,
    output reg [4:0] refund
);

endmodule
```

|             时间 | 应看到的现象                                                |
| ---------------: | ----------------------------------------------------------- |
|            25 ns | 投入 5，`credit=5`                                          |
|            35 ns | 金额不足，`insufficient=1`，余额仍为 5；45 ns 后变回 0      |
|            55 ns | 同拍投入 4 并购买，先加后扣，`credit=1`、`dispensing=1`     |

## 题二：带禁停与超载保护的电梯

大楼为 1～8 层。一次只接受一个目标，输入均与 `clk` 同步；为了简化，不考虑开关门和乘客进出过程。

1. `rst_n=0` 时异步复位：当前楼层和目标楼层都为 1。
2. 空闲时（`current_floor == target_floor`），若 `request=1`、目标在 1～8 内，且目标楼层合法，则该上升沿将目标保存到 `target_floor`。这一个沿**只保存目标**，下一上升沿起才开始移动。
3. 2、3 楼为禁停楼层；只有在接受请求的那个上升沿 `emergency=1`，才能把 2 或 3 设为目标。合法目标一经接受就保存，后续 `emergency` 变 0 仍继续前往。越界楼层和不满足条件的请求忽略。请求当前楼层可接受，但电梯不动。
4. 非超载且正在行进时，每个上升沿向目标移动一层，直到到达。行进中的新请求全部忽略；到达目标的那个上升沿沿前仍处于行进状态，因此该沿的新请求也忽略，下一个上升沿才可接受。
5. `people > 13` **或** `weight > 1000` 时，`alert=1`；人数恰好 13、重量恰好 1000 均不超限。`alert` 为组合输出。超限期间当前楼层和目标保持不变、请求无效；解除后继续前往原目标。
6. `busy` 为组合输出：当前楼层与目标不等时为 1；暂停但尚未到达时仍为 1。

```verilog
module elevator_ctrl(
    input clk, input rst_n,
    input request, input [3:0] requested_floor, input emergency,
    input [3:0] people, input [9:0] weight,
    output reg [3:0] current_floor, output reg [3:0] target_floor,
    output busy, output alert
);
```
