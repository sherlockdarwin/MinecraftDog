# 公开历年题来源与使用

资料来自 GitHub 用户 MrYanYe 的 [NUECSDC FPGA 能力测试资料仓库](https://github.com/MrYanYe/NUECSDC_FPGA_National_Competition_Verilog_Skills_Test_V1)。仓库作者说明其中部分材料转自其他来源，**不能保证全部年份和题目真实**；本目录按仓库标注年份整理，未能向赛事官方独立核实。

- [2020 年资料目录](https://github.com/MrYanYe/NUECSDC_FPGA_National_Competition_Verilog_Skills_Test_V1/tree/main/2020FPGA%E5%9B%BD%E8%B5%9B%E5%9F%BA%E7%A1%80%E8%83%BD%E5%8A%9B%E6%B5%8B%E8%AF%95)：本地 PDF 含四道题，可选一道练习；`2020_test1.v` 至 `2020_test4.v` 是仓库所附对应仿真文件，`2020_模块接口.txt` 是接口说明。下载时仅给文件名加了 `2020_` 前缀，文件内容未修改。注意 testbench 没有结束语句时用有限仿真时间，不能一直 `run -all`。
- [2023 年资料目录](https://github.com/MrYanYe/NUECSDC_FPGA_National_Competition_Verilog_Skills_Test_V1/tree/main/2023FPGA%E5%9B%BD%E8%B5%9B%E5%9F%BA%E7%A1%80%E8%83%BD%E5%8A%9B%E6%B5%8B%E8%AF%95)：本地 PDF 有电梯控制、固定分组序列检测，模块接口和 benchmark 印在 PDF 内。示例代码从 PDF 复制前应检查标点、端口声明及仿真时间，避免排版/OCR 带入语法错误。

上述 PDF 保持原样；来源仓库及原作者没有在仓库首页对每个文件的真实性作保证。练习前以具体题意为准，不要把参考模板直接当作该题完整答案。
