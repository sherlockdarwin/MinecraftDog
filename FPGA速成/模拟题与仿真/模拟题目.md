# Verilog 波形验收模拟题（三题）

这三题是根据现有题目练习的风格自行编写的，**不是历年真题**。每题独立完成；题目给出模块接口和配套 tb，只写设计模块。仿真时先把题目 tb、自己写的设计文件、`../verilog_templates/run.do` 复制到英文路径，例如 `E:/FPGA/exam1`。

三个 tb 都自带少量检查：Transcript 出现 `PASS` 表示覆盖的检查通过；还应自己对照完整题意看波形。tb 在时钟下降沿改变输入、上升沿后检查输出，避免与设计在同一个沿竞争。`run.do` 中 `TIME` 设为 `-all`，`TB` 和 `SRCS` 按每题填写。

## 题一：小型停车场计数

停车场最多停 5 辆车。输入 `enter`、`leave` 是同步的一拍请求。

1. 低有效异步复位后，`count=0`。
2. 每个上升沿：只有 `enter=1` 时，未满则加 1，满了保持 5；只有 `leave=1` 时，非空则减 1，空了保持 0。
3. `enter` 和 `leave` 同时为 1 时，无论当前是空、满还是中间值，数量保持不变；都为 0 时也保持。
4. `full` 在 `count==5` 时为 1；`empty` 在 `count==0` 时为 1。它们随 `count` 组合变化。

```verilog
module parking_ctrl(
    input clk, input rst_n,
    input enter, input leave,
    output reg [2:0] count,
    output full, output empty
);
// 在这里写代码
endmodule
```

运行：`TB tb_parking`，`SRCS {parking_ctrl.v tb_parking.v}`。波形至少检查：空时减不下去、数到 5 后不再增加、同时进出数量不变、离开后满标志消失。

## 题二：简化洗衣机控制

`start` 和 `stop` 均为同步输入；只按时钟上升沿采样。输出 `phase` 编码：`0` 待机、`1` 洗涤、`2` 漂洗、`3` 脱水；`busy` 表示不在待机。

1. 低有效异步复位后待机，`busy=0`。
2. 待机时采到 `start=1`，该上升沿后进入洗涤。洗涤持续 4 个完整时钟周期，然后漂洗持续 3 个周期、脱水持续 2 个周期，之后自动回待机。例如进入洗涤后的第 4 个上升沿切到漂洗。
3. 运行中忽略 `start`；任意状态采到 `stop=1` 则该上升沿后回待机，并清除计时。`stop` 的优先级高于 `start`。
4. `busy` 为组合输出：`phase!=0` 时为 1。新一轮从洗涤重新计时。

```verilog
module washer_ctrl(
    input clk, input rst_n,
    input start, input stop,
    output reg [1:0] phase,
    output busy
);
// 在这里写代码
endmodule
```

运行：`TB tb_washer`，`SRCS {washer_ctrl.v tb_washer.v}`。重点观察阶段切换边沿，尤其是进入洗涤后数满 4 拍才切换；还要看运行中再次启动、停止和重新启动。

## 题三：四位分组序列检测

输入 `din` 是串行的 1 位数据；`valid=1` 的上升沿才接收该位。每连续收到 **4 个有效位**作为一组，组与组不重叠。例如 `1011_1010` 是两组，不考虑跨组的四位。

1. 低有效异步复位清除当前组以及两个输出。
2. 每组的第 4 位采样完成的上升沿之后，若该组为 `1011`，`match` 高一个时钟周期；否则 `not_match` 高一个时钟周期。两个输出不同时为 1。
3. 其他周期两个输出都为 0。`valid=0` 时不接收数据，已收到的位和组内计数保持，输出脉冲仍需按时结束。
4. 组与组可以连续输入，上一组的末位之后，下一次有效输入就是下一组首位。

```verilog
module seq4_group(
    input clk, input rst_n,
    input valid, input din,
    output reg match, output reg not_match
);
// 在这里写代码
endmodule
```

运行：`TB tb_seq4_group`，`SRCS {seq4_group.v tb_seq4_group.v}`。观察 `1011` 匹配、`1010` 不匹配、输入中途插入 `valid=0`、连续两组的交界，以及两种输出脉冲均只持续一拍。
