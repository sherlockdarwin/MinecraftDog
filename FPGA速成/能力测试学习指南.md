## 一、考试到底考什么

每题给你一个写好的 **testbench**（tb 文件），你的任务是写出 **RTL 模块**，让 testbench 仿真后波形正确。

不需要综合，不需要上板，不需要写约束文件。

工具：用 **TD 6.2**（已在 `/reference/TD/TD_6.2`），新建工程→添加两个文件（tb + 你的模块）→仿真→对波形。

## 三、学习路线（按优先级）

### 阶段1：看懂接口（1小时）

读 testbench，重点提取：

1. **模块名** → 你写的 `module xxx` 名字必须完全一致
2. **端口列表** → `input/output` 名字、位宽完全一致
3. **信号时序** → 什么信号什么时候拉高，观察预期行为

技巧：先把 testbench 中 `initial begin...end` 里的操作序列读一遍，用中文写下"第几个时钟做了什么"。

### 阶段2：掌握2个核心模板（3小时）

#### 模板A：同步计数器（BCD/二进制均适用）

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        cnt <= 0;
    else if (cnt == MAX - 1)
        cnt <= 0;
    else
        cnt <= cnt + 1;
end
assign tick = (cnt == MAX - 1);  // 进位信号给上一级
```

BCD计数器：MAX=10，高4位十位，低4位个位，`[7:4]`是十位，`[3:0]`是个位。

#### 模板B：有限状态机（2段式，最清晰）

```verilog
// 状态定义
localparam S_IDLE = 2'd0, S_RUN = 2'd1, S_LOCKED = 2'd2;
reg [1:0] state;

// 时序：只管转移
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) state <= S_IDLE;
    else        state <= next_state;
end

// 组合：描述每个状态转移条件
always @(*) begin
    case (state)
        S_IDLE:   next_state = cond_a ? S_RUN : S_IDLE;
        S_RUN:    next_state = cond_b ? S_LOCKED : S_RUN;
        default:  next_state = S_IDLE;
    endcase
end

// 输出逻辑
assign out = (state == S_RUN);
```

### 阶段3：用 AI 生成 + 自己验证（主要方法）

考场流程：

1. 读题→理解需求→告诉 AI：模块名、端口、功能要求
2. AI 给代码→在 TD 中建工程→粘贴 tb 和代码→仿真
3. 看波形是否符合预期→不对就描述给 AI 让它修

**关键：你要能看懂波形，判断哪个信号的时序不对，然后描述给 AI。**

## 四、TD 工具仿真操作步骤

1. 打开 TD → 新建工程（FPGA 型号无所谓，仿真不需要匹配）
2. 添加源文件：你的 RTL 文件 + testbench 文件
3. 设置 testbench 为仿真顶层（右键 tb 文件 → Set as Simulation Top）
4. 仿真 → Run → 查看波形窗口
5. 右键波形中的信号 → 选 Radix → Decimal/Hex 方便读数

## 五、考场紧急策略

- **先选简单的题**：交通灯和电子钟通常比密码锁、计费系统更直接
- **仿真跑起来但波形不全对**：看哪一段不对，只修那部分
- **AI 提示词模板**：
  > "用 Verilog 实现以下模块，模块名 XXX，端口如下：[粘贴程序头]。功能：[用自己话描述]。要求同步复位低有效。"
