# 答辩现场调参速查

本次前进 3100、原地转向 2100 的版本已编译为根目录的 `MinecraftDog_FPGA_3100_2100.bit`，可在 TD 下载窗口 Add 选择它，Mode 选 FLASH，点 Run；尚需上车验证。`MinecraftDog_FPGA_3100.bit` 是原地转向仍为 2200 的前一版。

下面的参数都在 `mcproject_code/src/rtl/mctop.v` 上方配置区，列的是当前源码值。现场改参数后要保存，在 TD 打开 `mcproject_code/MinecraftDog_FPGA.al`，点绿色 ▶ 重新编译；`phy_1` 出现 `bitgen complete` 后，在下载窗口选**本次编译**的 `MinecraftDog_FPGA_Runs/best_result/MinecraftDog_FPGA.bit`。每次只改一项，记下原值；改参数不会自动更新根目录的 bit。

**赶时间先看**：速度不合适 → `FOLLOW_START_PWM`；直行摇摆 → `FOLLOW_DEADBAND`、`HEAD_KP` / `HEAD_KD`；绕障太晚 → `AVOID_CM`；地板大片变紫 → `OBS_YSPREAD`；白墙看不到 → 先看屏幕 `TOF` 距离是否有效。

## 跟随和转向

| 参数 | 当前值 | 意思和现场怎么调 |
| --- | --- | --- |
| `FOLLOW_START_PWM` | 3100 | 基础前进量；太冲可小幅降低，起步不动或断续走就加回 3200、3300。原版是 3300，3100 尚待上车验证。 |
| `FOLLOW_KP_D` / `FOLLOW_MAX_FWD` | 10 / 5000 | 每远 1 cm 多加 10 PWM / 前进量上限。距离远了才冲：先减 `FOLLOW_KP_D`；很远仍太快再减上限。 |
| `FOLLOW_STOP_CM` | 200 cm | 离主人不超过这个距离就停；停太远调小，太近调大。尽量不小于 150，避免把主人的脚当障碍。 |
| `FOLLOW_ACC` / `FOLLOW_DEC` | 200 / 400 | 前进量每 20 ms 最多增加 / 减少多少；起步太猛可减小 `FOLLOW_ACC`。到达主人、丢信号等停车条件会直接停车，不受减速斜坡控制。 |
| `FOLLOW_DEADBAND` | 4° | 主人方向变化超过这个范围才改目标；跟着 UWB 抖动左右摆可加大，过大则转向迟钝。 |
| `FOLLOW_ANGLE_FILTER` | 3 | 主人方向每次跟上新测量的 1/3；UWB 方向抖动大可加大，过大则跟随转向变慢。 |
| `HEAD_KP` / `HEAD_KD` | 70 / 10 | 航向纠偏力度 / 转动阻尼。左右摆或转过头：先小幅减 `KP` 或加 `KD`；跟不上转弯：可加 `KP`，必要时相应加 `KD`。 |
| `HEAD_KI` | 20 | 缓慢补偿左右电机不一致；直行时 `TGT` 和 `YAW` 总差几度，可小幅加大。 |
| `HEAD_TURN_MAX` / `AVOID_TURN_MAX` | 1500 / 1500 | 普通跟随 / 绕障时的转向量上限；对应场景拐不过去可加大，过大可能转得更急。 |
| `FOLLOW_TURN_SLEW` | 800 | 转向量每 20 ms 最多变化多少；减小会让转向变化更缓，但反应也更慢。 |
| `FOLLOW_PIVOT_PWM` / `AVOID_SPIN_PWM` | 2100 / 2100 | 朝主人原地转 / 避障找出口原地转的力度，由 2200 小幅降低。若转不动或断续转，先把对应项加回 2200；需上车验证。 |

空旷直行时，前进目标为 `min(5000, 3100 + (主人距离cm − 200) × 10)`；例如 2.5 m 是 3600、3 m 是 4100。靠近障碍时还会受避障限速；左右轮会另外叠加转向量。

## 避障和画面

| 参数 | 当前值 | 意思和现场怎么调 |
| --- | --- | --- |
| `AVOID_CM` / `AVOID_SPIN_CM` | 100 / 60 cm | 前方或主人方向小于 100 cm 开始绕；正前方小于 60 cm 原地转。想更早反应可加大；相机最近只能看到约 49 cm，原地转门限不要小于 55 cm。 |
| `AVOID_FAR_CM` / `AVOID_OWNER_GAP_CM` | 200 / 60 cm | 主人方向提前绕的最远范围 / 障碍要比主人近至少多少。误把远处反光当障碍可减前者；快到主人时绕开其腿可加后者。前者不大于 `AVOID_CM` 时不提前绕。 |
| `AVOID_HOLD_CM` | 50 cm | 绕完后先保持航向走的估算距离；绕过后太早拐回去可加大。距离按电机命令估算，非实测里程。 |
| `AVOID_KP_OBS` | 20 | 障碍附近前进限速的增长系数；靠近障碍仍太快可减小，但过小可能影响起步。 |
| `OBS_YSPREAD` | 2 | 地面亮度宽容度；大片地板误判成紫色障碍可加大，障碍与地面亮度太像可减小。收得太紧会让反光地面粘成紫色。 |
| `OBS_TC` / `OBS_TY` | 15 / 15 | 色度 / 亮度门限；零星紫点多可减小，障碍漏判可加大。大片地板发紫优先看 `OBS_YSPREAD`。 |
| `OBS_ROW_MIN` | 53 | 从画面哪一行开始判断障碍；53 约看到 2.36 m，改 60 约只看到 1.35 m，可减少远处反光误判，但也会减少提前发现距离。不要小于 53。 |
| `TOF_MAX_CM` / `TOF_FREEZE_CM` | 120 / 80 cm | 激光的有效最远距离 / 多近时暂停学习地面。空前方却显示 80～120 cm，先检查激光是否照到地面、调整朝向，再考虑减小前者；后者为 0 表示不暂停。 |
| `TOF_SIDE` | 2 | 激光距离覆盖正前方两侧各几个方向；2 约为 ±9°，范围 0～4。 |

## 音量及现场检查

`AUD_SPK_VOL = 22`：喇叭音量，越大越响；原记录中调到 33 曾尖叫、拉低电源，不要贸然调大。`BARK_CM = 999`、`BARK_MS = 1000`：主人约 10 m 外或 UWB 丢失持续 1 秒后叫；困住时也会叫。

1. 车静止上电，确认屏幕 `UWB OK`、`IMU OK`；手动向右转车，`YAW` 应增大。前方留出空间，先试起步、停车和跟随转弯。
2. 看处理画面：地面以绿色为主，障碍显示紫色；再用箱子试提前绕、近处绕和原地转。一次只调整对应的一项。
3. 激光还需上车验证：看第 3 行 `TOF` 距离，前方约 50 cm 放手时应有对应读数；`255 cm` 表示当前无可用距离或超出有效范围，不能据此认为墙是安全的。`NOLK` / `LOST` 先查供电、接线和模块数据。激光不可用时只剩视觉避障，浅色墙可能漏检。

原始备份 `bit_restore/MinecraftDog_FPGA_6.0_distance.bit` 可用于恢复。旧的 `src/boot/MinecraftDog_FPGA.bit` 与该备份逐字节一致；修改前的源码重新编译后，除文件头生成时间外也与备份一致。降速后的 bit 自然不同；原工程内已有的 `best_result` 是更早的版本，使用前要确认它已由本次编译更新。
